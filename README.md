## فارسی

فورس نتورک سل ابزاری برای بررسی شبکهٔ موبایل و دسترسی آسان‌تر به تنظیمات نوع شبکه است. اطلاعات اتصال، قدرت سیگنال و داده‌های سلول و باند را در حدی که گوشی و اپراتور گزارش می‌کنند مشاهده کنید.

روش‌های مختلف برای بازکردن صفحهٔ اطلاعات تلفن و تنظیمات شبکه در نسخه‌های متفاوت اندروید در نظر گرفته شده‌اند. در گوشی‌های سازگار، می‌توانید از صفحهٔ سیستمی برای انتخاب حالت‌هایی مانند LTE only یا فقط 4G استفاده کنید. ابزارهای عیب‌یابی اتصال نیز در برنامه قرار دارند.

دسترسی به این صفحه‌ها و گزینه‌های قابل انتخاب به سازنده، نسخهٔ اندروید و اپراتور وابسته است. برنامه نوع شبکه را خودکار تغییر نمی‌دهد. انتخاب LTE only ممکن است در نبود VoLTE بر تماس تلفنی اثر بگذارد.

این برنامه دارای تبلیغات است.

### شروع کار

از روش مناسب نسخه اندروید برای بازکردن اطلاعات شبکه استفاده کنید. در صفحه سیستم، نوع شبکه را خودتان انتخاب کنید؛ در صورت مشکل اتصال، تنظیم قبلی را برگردانید. سازگاری به گوشی و اپراتور بستگی دارد.

### تبلیغات

بنر استاندارد بالای نوار ناوبری. نبود تبلیغ مانع استفاده از برنامه نمی‌شود.

## English

Force Network Cell helps you inspect mobile connectivity and reach network mode settings more easily. View connection details, signal strength, cell information and band data when your device and carrier make them available.

Several methods are provided for opening phone information and network settings across Android versions. On compatible phones, the system screen may let you select modes such as LTE only. Connection diagnostic tools are also included.

Access to these screens and the available choices depend on the manufacturer, Android version and carrier. The app does not change the network mode automatically. LTE-only mode may affect calling when VoLTE is unavailable.

This app contains advertising.

### Getting started

Choose the method appropriate for your Android version to open system phone information. Select the network mode yourself and restore the previous setting if connectivity suffers. Availability depends on the phone and carrier.

### Advertising

Standard banner above navigation. An unavailable ad does not block ordinary use.
